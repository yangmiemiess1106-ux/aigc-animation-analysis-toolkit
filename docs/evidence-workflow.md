# Video evidence workflow

This workflow is designed for transparent, repeatable observation of short animations. It describes how to create an auditable record without distributing the source video.

## 1. Register provenance

For each case, record a stable case ID, title, source URL, access date, rights note, duration, frame rate (if available), and any limitations in access. Do not infer production tools from the visual result alone.

## 2. Build three evidence layers

1. **Overview sampling:** inspect the whole work at regular time intervals to understand its structure.
2. **Scene sampling:** record shot or scene boundaries and representative frames.
3. **Motion sampling:** inspect short continuous frame windows for movement, temporal consistency, and transitions.

Each observation should include a time range and an evidence ID that maps back to the researcher's private evidence inventory.

## 3. Separate observation from interpretation

Write what is visibly or audibly present in `observation`. Write the analytical significance in `interpretation`. If a claim requires historical, production, or contextual evidence beyond the video, cite that separate source.

## 4. Record gaps

If a source cannot be accessed, only a static image is available, or a motion window is too short, record the limitation explicitly. A gap is not evidence of a visual defect.

## 5. Preserve privacy and rights

Keep original videos, extracted frames, private research notes, and sensitive metadata outside the public repository unless redistribution is clearly permitted. Public examples in this repository should be synthetic or openly licensed.
